# Frontend (React + Vite + Tailwind)

## Key ideas
- `src/pages`: route-level views
- `src/components`: reusable UI and layout pieces
- `src/hooks`: custom hooks for stateful logic
- `src/services`: API clients and domain API functions
- `src/context`: app-wide providers (auth, theme, etc.)

## Quick start
1. `npm install`
2. `cp .env.example .env`
3. `npm run dev`
