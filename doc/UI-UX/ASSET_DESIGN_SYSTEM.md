# Asset Design System

## Phase 11 Goal
Create a restrained motif library for Tara's day and night world.

The assets should feel:
- minimal
- elegant
- cinematic
- never cartoon-heavy

They are not the main design.
They are supporting atmosphere.

## Asset Set

### Night
- `moon-treatment.svg`
  - a refined crescent with a few restrained star accents
- `star-field.svg`
  - a sparse repeatable star tile for background layering
- `owl-silhouette.svg`
  - a softened perched owl silhouette, meant to feel distant
- `constellation-marks.svg`
  - delicate dots and partial connecting lines

### Day
- `cloud-shapes.svg`
  - soft cloud masses with no comic-style outlines
- `sunrise-bird.svg`
  - a minimal sunrise + bird silhouette gesture

## Usage Rules
- motifs belong on hero surfaces, scene headers, and selective empty states
- motifs should sit near edges, never over dense content
- large data areas should stay mostly motif-free
- silhouettes must remain subtle enough to feel discovered, not announced

## Integration Rule
- keep the existing gradient-based world-building
- blend assets into it rather than replacing it
- let CSS still carry most of the atmosphere
- use SVG motifs as accents, not wallpaper

## Export Notes
- assets are optimized SVGs
- no embedded metadata
- simple paths and shapes only
- suitable for CSS background use without runtime processing
